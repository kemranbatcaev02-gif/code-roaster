## ✨ Возможности

- 🎭 **4 уникальные личности ревьюеров**:
  - 👴 **Сеньор-Помидор Геннадий** (`senior`): Ворчливый архитектор старой школы (25 лет опыта на Fortran).
  - 🔪 **Шеф Гордон Рамзи** (`ramsay`): Беспощадный крик, паника и сравнение кода с сырым стейком.
  - 🤖 **Кибер-Аудитор v9000** (`cyber`): Хладнокровный ИИ, протоколирующий деградацию белкового разума.
  - ☕ **Пассивно-Агрессивный Тимлид** (`teamlead`): «Интересное решение... а ты сам на прод это деплоить будешь?»
- 🎯 **Мультиязычный анализ**: Поддерживает Python, Go, Rust, TypeScript, JavaScript, C/C++, Java, Kotlin, Dart, PHP, C# и другие.
- 🪵 **Прожарка Git-истории (`--git`)**: Выявляет коммиты-загадки вроде `fix`, `update`, `asdf`, `wip`, `1`.
- 📊 **Индекс прожарки (Flame Score)**: От `0/100` (Святой код) до `100/100` (Чернобыль репозитория 🔥).
- ⚡ **Ноль внешних зависимостей**: Написан на чистой стандартной библиотеке Python 3.8+!

## 🚀 Быстрый старт

### 1. Прожарить текущую папку
```bash
python roaster.py .
```

### 2. Выбрать своего ревьюера
```bash
# Прожарка от Гордона Рамзи
python roaster.py . --persona ramsay

# Прожарка от Пассивно-Агрессивного Тимлида
python roaster.py . --persona teamlead

# Прожарка от Кибер-Аудитора
python roaster.py . --persona cyber
```

### 3. Прожарить конкретный файл или коммиты
```bash
# Прожарка одного файла
python roaster.py src/main.py --persona senior

# Включить анализ истории коммитов git
python roaster.py . --git
```

## 💡 Подключение в Git Pre-Push Hook

Хотите, чтобы перед каждым `git push` ваш код проходил проверку на токсичность?

Добавьте в файл `.git/hooks/pre-push`:
```bash
#!/usr/bin/env sh
python path/to/code-roaster/roaster.py . --persona teamlead
```
