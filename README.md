## ✨ Возможности

- 🎭 **5 уникальных личностей ревьюеров**:
  - 👴 **Сеньор-Помидор Геннадий** (`senior`): Ворчливый архитектор старой школы (25 лет опыта на Fortran).
  - 🔪 **Шеф Гордон Рамзи** (`ramsay`): Беспощадный крик, паника и сравнение кода с сырым стейком.
  - 🤖 **Кибер-Аудитор v9000** (`cyber`): Хладнокровный ИИ, протоколирующий деградацию белкового разума.
  - ☕ **Пассивно-Агрессивный Тимлид** (`teamlead`): «Интересное решение... а ты сам на прод это деплоить будешь?»
  - 🐣 **Джуниор Саня** (`junior`): «Я не знаю, почему это работает, пожалуйста, НЕ ТРОГАЙТЕ НИЧЕГО!»
- 🔍 **Комплексный анализ антипаттернов**:
  - 🔓 **Хардкоженные секреты**: Токены, пароли, API-ключи, Bearer-заголовки.
  - 💉 **SQL-инъекции**: Небезопасная строковая интерполяция и склейка SQL-запросов.
  - 🌌 **Wildcard-импорты**: Загрязнение пространства имен (`from ... import *`).
  - 🔮 **Магические числа**: Безымянные константы и непонятные числовые значения.
  - 🤡 **Ленивый нейминг**: Переменные вроде `temp`, `data2`, `test1`, `asdf`, `kek`.
  - 🗑️ **Отладочный спам**: Забытые `print`, `console.log`, `fmt.Println`, `dbg!`.
  - 🦹 **Проглоченные ошибки**: Пустые блоки `except: pass` и `catch {}`.
  - 🧟 **Зомби-код**: Закомментированные логические конструкции и функции.
- 📑 **Многоформатный экспорт**:
  - `--format terminal` — Цветной CLI-вывод с ASCII-артом.
  - `--format markdown` (`--markdown`) — Готовый отчет для GitHub PR и Issues.
  - `--format html` (`--html`) — Автономная стильная страница в Dark Mode.
  - `--format json` (`--json`) — Структурированные данные для скриптов.
- 🚨 **CI/CD Quality Gate (`--max-score <N>`)**:
  - Завершение с кодом `1`, если Flame Score превышает заданный порог.
- 🪵 **Прожарка Git-истории (`--git`)**: Выявление коммитов-загадок (`fix`, `upd`, `test`).
- ⚡ **Ноль внешних зависимостей**: Написан на стандартной библиотеке Python 3.8+!

## 🚀 Быстрый старт

### 1. Прожарить текущую папку
```bash
python roaster.py .
```

### 2. Экспорт отчета в Markdown или HTML
```bash
# Сохранить красивый отчет в Markdown
python roaster.py . --markdown -o roast_report.md

# Сгенерировать интерактивный HTML-дашборд
python roaster.py . --html -o audit.html
```

### 3. Выбрать ревьюера
```bash
# Прожарка от Гордона Рамзи
python roaster.py . --persona ramsay

# Прожарка от Пассивно-Агрессивного Тимлида
python roaster.py . --persona teamlead

# Прожарка от Кибер-Аудитора
python roaster.py . --persona cyber

# Прожарка от Джуниора Сани
python roaster.py . --persona junior
```

### 4. Использование в CI/CD пайплайнах
```bash
# Завершить билд ошибкой, если индекс прожарки выше 40
python roaster.py . --max-score 40 --format markdown -o report.md
```
