# Участие в разработке Code Roaster

Мы рады новым идеям, правилам линтинга и забавным личностям ревьюеров!

## Как добавить новую личность:
1. Откройте `roaster.py`.
2. В словаре `PERSONALITIES` добавьте новый ключ с ASCII-аватаром и набором фраз для `flame_comments`.
3. Добавьте юнит-тест в `tests/test_roaster.py`.
4. Откройте Pull Request!
