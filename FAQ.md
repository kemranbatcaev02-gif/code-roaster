# Часто задаваемые вопросы (FAQ)

### 1. Как Code Roaster находит костыли?
Утилита использует легковесный синтаксический анализ и регулярные выражения для поиска типовых антипаттернов: ленивых имен переменных (`temp`, `data2`, `test1`), забытых отладочных принтов, проглоченных ошибок (`except: pass`), вечных `TODO` и закомментированного старого кода.

### 2. Изменяет ли утилита файлы?
Нет! Code Roaster работает исключительно в режиме чтения (Read-Only) и никогда не модифицирует исходный код.

### 3. Можно ли добавить свои правила или фразы?
Да! Словарь `PERSONALITIES` в `roaster.py` позволяет легко добавлять собственные фразы и настраивать жесткость комментариев.
